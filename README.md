# C++ Storage Learning

> 从现代 C++ 到存储引擎，再到 AI Infra 的系统学习记录。

## 📖 项目简介

本仓库用于记录我学习现代 C++、存储系统以及 AI 基础设施（AI Infrastructure）的全过程。

学习不仅关注 C++ 语法，更注重工程实践、系统编程思想以及底层存储系统设计，希望最终能够独立完成一个简化版存储引擎（MiniLSM）和一个分布式 Key-Value 存储系统。

---

## 🎯 学习目标

* 学习现代 C++（C++17/20）
* 掌握 Linux 系统编程基础
* 理解存储引擎核心原理
* 实现 MiniLSM
* 实现简化版分布式 KV 存储
* 学习 AI Infra 相关基础设施
